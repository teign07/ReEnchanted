ReEnchanted iOS App Setup

This repository contains the current InsideCover/ReEnchanted iOS app, its
shared SwiftPM core, tests, a static landing page, and a separate Remotion promo
project.

Quick start:

1. Open EnchantifyInsideCover.xcodeproj in Xcode.
2. Select the InsideCoverApp scheme.
3. Choose an iOS simulator to run without signing changes, or choose a physical
   iPhone/iPad and set your Apple development team.
4. Run the app.

Command-line checks from the repository root:

  CLANG_MODULE_CACHE_PATH=/private/tmp/insidecover-module-cache \
  SWIFTPM_MODULECACHE_OVERRIDE=/private/tmp/insidecover-spm-module-cache \
  swift test

  xcodebuild \
    -project EnchantifyInsideCover.xcodeproj \
    -scheme InsideCoverApp \
    -configuration Debug \
    -destination 'generic/platform=iOS Simulator' \
    -derivedDataPath /private/tmp/InsideCoverDerivedData \
    build

If SwiftPM/XCTest provenance or signing causes local test trouble, use:

  scripts/swift-test-resigned.sh

Useful paths:

  PROJECT_OVERVIEW.md                 product and architecture guide
  InsideCoverApp/                     SwiftUI app target files
  Shared/                             shared models, curation, story systems
  Tests/InsideCoverCoreTests/         shared core tests
  Sample/                             bundled/sample payloads
  scripts/                            local validation and generation helpers
  LandingPage/                        static marketing page
  RemotionPromo/                      standalone promo video project

Local brain note:

The app has resilient fake/fallback paths when local model assets are missing.
Simulator builds compile and exercise those fallbacks. The native local-brain
path is intended for physical devices when the optional MLX/Gemma pieces are
available.

Data note:

The app is local-first. Personal continuity can be exported/imported as a
.reenchanted-save.json file. The old widget-state import workflow is no longer
the primary setup path, and the widget source is intentionally detached from this
app target.
