# November 2026 art

The commissioning brief is `ContentPacks/the-guest/art-prompts.json`, generated by
`make_art_prompts.py`: 20 plates, 20 seasonal cutouts and 8 directed margin marks.
The two existing covers are separate from those 48 commissions.

The current app artwork supplies the visual references. The kitchen interleaf
and goblin supply the plate medium; the existing pixie, goblin and October
cutouts supply the marginalia medium. Cast plates use the actual character
portraits. Guest appearances use the existing Guest dossier, with the face
concealed. Reference filenames resolve from asset-catalog `Contents.json` rather
than assuming every portrait is HEIC. Every generation records its actual
inputs, full prompt, source and review in `art-provenance/`.

## Sources and exports

All paths below are inside `ContentPacks/the-guest/`.

| Directory | Purpose |
|---|---|
| `plates/` | Native generated PNG masters, without upsampling |
| `publication-plates/` | JPEG exports for the bound editions |
| `story-art/` | Eight JPEG attachments for the living Book's story passages |
| `seasonal-marginalia/` | Twenty PNGs with real alpha and transparent padding |
| `marginalia/` | Eight sparse pen marks with real alpha and transparent padding |
| `art-masters/` | Original cutouts preserved before export optimization |
| `art-candidates/` | Superseded candidates, excluded from issue delivery |
| `art-review/` | Contact sheets, export manifest and offline validation report |

`prepare_art.py` uses Pillow to make delivery exports. It never generates art,
redraws a subject, removes faint painted strokes or enlarges native masters.
Every export stays below 2 MiB with a 64 KiB safety margin. Cutouts keep their
alpha; the script adds transparent room around the complete generated canvas.
Cutout exports use the brief's 1024-pixel size, reducing it only if needed for
the delivery cap; the larger native originals remain available for print work.
Re-running derives cutouts from the preserved originals, avoiding repeated
resampling. The manifests retain dimensions and hashes.

The generator has returned native 1024 × 1536 portrait and 1536 × 1024 landscape
plates, below the brief's requested print dimensions. `validation.json` records
that as a print-resolution warning. Export preparation does not establish print
quality at the final physical size; a printed or rendered edition proof remains
necessary.

## Integration

The existing shared marginalia cabinet receives the 28 cutouts through
`content_art.py` and `content_margins.py`. The seasonal set is gated to November
2026. Directed marks stay out of general decoration selection and wait for the
relevant completed scene; the final thorn waits until residue. Existing snippet
text stays native text rather than becoming generated lettering.

Story plates attach to the exact depicted node. Bonfire Night uses
`three-nights.bonfire`; the cooking scene uses `the-rescue.cooking`. The other six
main scenes use their entry nodes. Continuations and alternate answers do not
inherit an image from a different passage. Existing media inspection and kept
Page archival behavior apply without adding another image system.

`issue.json` uses new immutable delivery identities:
`the-guest.runtime.v3`, `the-guest.margins.v2`, `the-guest.story-art.v1.*`,
`the-guest.seasonal.v1.*`, `the-guest.mark.v1.*` and `the-guest.v1.plate.*`.
Publication and runtime media retain separate delivery scopes.

The bundled November cover schedule puts *A Place at the Table* first, with
*The Other Supper* available as an alternative. Both images already contain
their title and date, so `artworkIncludesCoverMatter` prevents another title
being typeset over them. The existing per-month cover selection handles choice.

## Checks and review

Run `prepare_art.py` with the bundled Python runtime that includes Pillow, then
`scripts/check_november_art.py`. The latter checks source references, alpha,
dimensions, runtime media resolution, directed gates and delivery sizes without
compiling the app. `scripts/monthly_issue.py stage` checks the actual issue
delivery tree offline; it does not upload or publish anything.

Contact sheets support review of the full commissioned set. Source validation
and image inspection do not establish app rendering, interaction, device
performance, printed quality or publication. No app build is authorized as part
of this art work.
