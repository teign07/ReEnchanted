# Attic

Code kept because it may be wanted back, saved as plain files rather than left
to git history alone — history is findable only if you know what you are looking
for, and a filename is a reminder that a decision was made.

## `LiteraryContinuity.pre-scene-plan.swift`

The whole braid file as it stood before the scene-plan architecture began
switching the default renderer. Saved 2026-08-17 at commit `8ce4499`.

It contains the complete sentence-bank writer: `taleThreads` (sixteen world
threads with opening/continuation/resolution), `keepingMoves`, `supportingMove`,
`crossingMove`, `arcMove`, `relationalMove`, `voiceBite`, the colophon variants,
the settling and filler loops, and the word-band padding mechanism.

**Why it is here.** The plan-driven floor is provably honest and reads thinner:
46 words against 115 on a plain day, 151 against 307 on a rich one. Most of that
gap is padding we measured and set out to remove, but "thinner and honest" versus
"fuller and padded" is a judgement about the product, and it has not been tried
on a device yet. If the floor reads too thin in practice, the prose to bring back
is in here.

**What is *not* worth bringing back**, on the evidence:
- The anchor-noun interpolation. 80 of 81 world strings took the night's subject
  as an argument, which is why the world could never act on its own.
- The filler loop. Three separate budget cuts moved the Book's self-narration by
  zero sentences; the band was the only lever, and raising it bought 98 words of
  which none were the reader's.
- The five identical blank-day pages.
