HOW TO RECORD (ElevenLabs)
------------------------------------------------------------------------
• ONE VOICE PER DJ — keep it identical across all of that host's clips so
  the station sounds like one real broadcaster.
• The [brackets] are ElevenLabs v3 audio tags (e.g. [dryly], [warmly],
  [softly], [low], [smooth], [amused], [cool], [precise]). ElevenLabs
  interprets them; it does not read them aloud. They are OPTIONAL — delete
  them if you prefer a flat read. (The Swift `caption` text in Part 2 is
  already the plain, bracket-free version.)
• Ellipses … and em-dashes — buy natural pauses.
• File naming: save each export as  <filename>.m4a  (or .mp3/.wav/.aac/
  .caf/.aiff). The filename is the heading shown for each clip.
• Drop finished audio into  InsideCoverApp/RadioAudio/  (bundled) or, at
  runtime, Documents/Radio or Documents/RadioPacks. Until a file exists,
  the caption plays on-screen as the break, so you can test cadence first.
